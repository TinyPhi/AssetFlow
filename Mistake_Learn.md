# Mistake_Learn.md

Kinds of mistakes agents made here: the rule, the learning, and links to every trace in
[Mistake_Traces.md](Mistake_Traces.md). Loaded every session via `CLAUDE.md`: check your diff
against every row before you finish.

- **Before adding**, search: `python scripts/check-mistakes-log.py find <words>`. A repeat is a new
  trace on the same kind (`seen M-NNN ...`), never a new row.
- **New kind** (made twice, or once if it broke CI or security): `new --area ... --why ...`.
- Rows and links are generated; do not edit them by hand. `make lint` checks both files.
